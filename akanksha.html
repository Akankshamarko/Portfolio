DermaBlue is a smart, personalized skincare platform that analyzes each user's skin type, concerns, and lifestyle to recommend the perfect skincare routine. Built with the MERN stack, it makes professional-grade skincare guidance accessible and personal.

React.js Node.js MongoDB Tailwind CSS Express.js REST API

Minimal, elegant interface built with Tailwind CSS — focused on clarity and ease of use.
